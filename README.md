# Обработка музыкальных файлов

1. подготовьте список файлов в формате `m3u` с корнем в директории `~/Музыка`; он не должен быть слишком длинным, оптимальный размер 10-15 строк, иначе текстовой агент может не успеть обработать теги;
2. подготовьте `yaml`-файл с помощью команды `m3u2yaml`, например `m3u2yaml 4000-the-best-of-j-j-cale.m3u`; 
3. сгенерированный файл (в данном примере — `4000-the-best-of-j-j-cale.m3u`) отправьте для обработки текстовому агенту; обычно это осуществляется посредством выгрузки в `aws`-бакет веб-приложения;
3. полученный от текстового агента скрипт (в данном примере — `4000-the-best-of-j-j-cale.sh`) запустите в директории с музыкальными файлами; он расставит насыщенные теги в mp3-файлах, упомянутых в плей-листе;
4. перенесите данные из тегов в БД с помощью утилиты `m3u2db` (в данном примере — `m3u2db 4000-the-best-of-j-j-cale.m3u`);
5. обработав некоторое количество прейлистов, запустите скрипт `refresh-embeddings.py`; это лучше сделать в ночное время, так как обработка (формирование векторов) может занять несколько десятков минут;
6. не забудьте сформировать резервную копию БД (`make dump`) по окончании работы.
