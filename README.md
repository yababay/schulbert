# Настройка голосового помощника

1. выполните `make setup`; установка производится в директорию `/usr/share/schulbert/music-voice-assistant`, перейдите в неё после успешного выполнения этой команды; 
2. установите (скачайте, скопируйте, распакуйте из архива) модель `vosk-model-small-ru-0.22` или похожую версию в директорию `models`;
3. создайте в директории `models` символическую ссылку: `ln -s vosk-model-small-ru-0.22 vosk-model-small-ru`;
4. пропишите параметры соединения с БД `PostgreSQL` в файле `.env`.
